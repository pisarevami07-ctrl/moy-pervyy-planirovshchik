# Мой первый планировщик

«Мой день» — личный планировщик с главными и мелкими задачами, фиксированными делами, перерывами и расписанием текущего дня. Все данные сохраняются в браузере через `localStorage`.

## Запуск

Откройте [планировщик «Мой день»](https://pisarevami07-ctrl.github.io/moy-pervyy-planirovshchik/) в браузере. Для локального запуска откройте `index.html` в Chrome или Edge; `style.css` и `script.js` должны лежать рядом. Установка и сервер для локальной версии не нужны.

В [архиве «Мой день.zip»](<Мой день.zip>) лежит готовая программа с инструкцией. Распакованная копия находится в папке [«Мой день»](<Мой день>).

## Возможности

- Главные и мелкие задачи с длительностью или фиксированными часами.
- Изменение приоритета порядком карточек и перенос мышью, касанием или кнопками.
- Автоматическое расписание с перерывами, бытовыми блоками и предупреждениями о перегрузке и пересечениях.
- Прогресс сегодняшних задач, выполнение по частям, архив и постоянная отмена выполнения.
- «Не сегодня» для отложенных дел; «Незавершённые» для задач других дат.
- Новая фраза дня, предустановки завтрака, обеда и сборов в школу с возможностью изменения.
- JSON-копии, проверяемое восстановление, очистка старого архива и защита несохранённых изменений.

## Перенос данных в опубликованную версию

Локальная и опубликованная версии имеют разные области хранения. Если вы уже планировали день локально, сначала скачайте JSON через «Резервная копия». Затем откройте опубликованный планировщик и восстановите этот файл через то же меню. Данные также переносятся таким способом между браузерами и устройствами.

## Публикация

Источник GitHub Pages: ветка `main`, папка `/` (корень). Файл `.nojekyll` оставляет HTML, CSS и JS обычными статическими файлами. Публикация не добавляет сервер, базу данных или передачу задач на GitHub: содержание задач хранится в браузере посетителя.
